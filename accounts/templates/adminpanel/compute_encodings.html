How it works

  • 1 This tool scans every student profile that has a photo uploaded.
  • 2 For each student, it computes a 128-dimensional face encoding (mathematical fingerprint) and stores it in the database.
  • 3 During live scanning, these cached encodings are loaded into memory once, making each face match take only ~100ms instead of several seconds.
  • 4 Re-run this whenever you add new students or update profile photos.
